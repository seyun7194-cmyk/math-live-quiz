# 비례의 전설

초등 수학 6-2 4단원 「비례식과 비례배분」을 학급 전체가 휴대폰·태블릿으로 동시에 복습하는 실시간 퀴즈 게임입니다.
선생님이 방을 만들면 학생은 QR 코드로 들어와 각자 속도로 문제를 풀고, 선생님 화면에는 순위가 막대 레이스로 실시간으로 나옵니다.
문제는 게임을 시작할 때마다 데이터베이스가 새로 만듭니다(28개 유형, 4단계 난이도).

## 들어 있는 파일

```
index.html        첫 화면 (선생님 / 학생 고르기)
teacher.html      선생님 화면 (방 만들기 → 대기실 → 게임 중 → 결과)
student.html      학생 화면 (입장 → 기다리기 → 문제 풀기 → 게임 끝)
style.css         연보라 파스텔 글래스 디자인
common.js         공통 도구 (서버 시계, 분수 표시, 동물 아바타, 실시간 연결)
config.js         Supabase 주소와 키 ← 여기만 고치면 됩니다
images/           아이콘
supabase/
  setup.sql           데이터베이스 한 번에 설치 (01~03을 합친 파일)
  01_tables.sql       표와 권한
  02_generator.sql    문제 자동 생성기
  03_functions.sql    선생님·학생 함수
  04_cleanup_cron.sql (선택) 오래된 방 자동 삭제
```

빌드 도구가 없는 HTML·CSS·JavaScript 파일이라 그대로 올리면 됩니다.

---

## 1. Supabase 준비 (10분)

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 만듭니다. 무료 플랜이면 충분합니다. 지역은 Seoul(Northeast Asia)을 고르면 빠릅니다.
2. 왼쪽 메뉴 **SQL Editor** → **New query**를 엽니다.
3. `supabase/setup.sql` 파일 내용을 전부 붙여 넣고 **Run**을 누릅니다. "Success"가 나오면 끝입니다. 여러 번 실행해도 괜찮습니다.
4. (선택) 오래된 방 자동 삭제: **Database → Extensions**에서 `pg_cron`을 켠 뒤, `supabase/04_cleanup_cron.sql`을 같은 방법으로 실행합니다.
   켜지 않아도 새 방을 만들 때마다 만든 지 24시간이 지난 방은 지워집니다.
5. 실시간 확인: **Database → Publications → supabase_realtime**에 `rooms`, `players` 두 표가 켜져 있는지 봅니다. setup.sql이 자동으로 켜 두지만, 꺼져 있으면 두 표만 켜 주세요.

## 2. config.js 고치기

**Project Settings → API**(또는 **API Keys**)에서 두 값을 복사해 `config.js`에 넣습니다.

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://abcdefgh.supabase.co',   // Project URL
  SUPABASE_ANON_KEY: 'eyJhbGciOi...'              // anon public 키 (또는 sb_publishable_ 로 시작하는 키)
};
```

- anon(publishable) 키는 브라우저에 공개되도록 만든 키라 GitHub에 올라가도 괜찮습니다. 데이터는 아래 「보안」의 규칙이 지킵니다.
- **service_role(secret) 키는 절대 넣지 마세요.**

## 3. GitHub에 올리기

**웹에서 끌어다 놓기(가장 쉬움)**
1. GitHub에서 **New repository** → 이름(예: `proportion-legend`) → **Create repository**
2. **uploading an existing file**을 누르고 이 폴더의 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**

**명령어로 올리기**
```bash
cd proportion-legend

```

## 4. Vercel로 배포

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인 → **Add New… → Project**
2. 방금 만든 저장소 옆 **Import**
3. **Framework Preset: Other**, Build Command와 Output Directory는 비워 둡니다.
4. **Deploy** → 1분 뒤 `https://proportion-legend.vercel.app` 같은 주소가 생깁니다.

이후에는 GitHub에 고친 파일을 올릴 때마다 Vercel이 자동으로 다시 배포합니다.

## 5. 수업 전 5분 점검

1. 노트북에서 `주소/teacher.html` → 난이도·시간 고르고 **방 만들기**
2. 휴대폰 2대(또는 휴대폰과 다른 브라우저 탭)로 QR 코드를 찍어 들어가기
3. **게임 시작** → 두 화면에 문제가 나오는지, 선생님 화면 막대가 움직이는지 확인
4. **게임 종료** → 학생 화면의 순위가 시상대와 같은지 확인
5. **학생 기록 지우기**

학생 화면 위쪽에 "자동 새로고침 중"이 보이면 실시간 연결이 안 되어 1.5~2초마다 새로 불러오는 상태입니다. 게임은 계속되지만, 1번의 5단계(실시간 확인)를 다시 봐 주세요.

## 게임 규칙 요약

- 정답 1점, 골든 타임(20초) 중 정답 2점, 오답 0점. 오답 뒤 1초 동안은 답을 받지 않습니다.
- 순위: 점수 → 맞힌 수 → 먼저 들어온 순서
- 미스터리 상자: 정답일 때 지금 순위가 상위 ⅓이면 10%, 중간 ⅓이면 20%, 하위 ⅓이면 30% 확률로 +1~+3
- 블라인드: 켜 두면 마지막 30초 동안 선생님 화면의 순위를 가립니다. 게임 중 버튼으로도 켜고 끌 수 있습니다.
- 결과 화면은 1~5위만 크게 보여 주고, 6위부터는 **전체 순위 보기**를 누를 때만 펼칩니다.

## 난이도별 문제

| 단계 | 섞는 비율 | 다루는 것 |
| --- | --- | --- |
| 1 기초 | A 100% | 전항·후항, 외항·내항, 비의 성질 O/X, 비례식 O/X, 용어 |
| 2 유형 연습 | A 20% + B 80% | □ 구하기, 간단한 자연수의 비(자연수·소수·분수), 비례배분 |
| 3 응용 심화 | B 30% + C 70% | 분수와 소수가 섞인 비, 비례식 세우기, 문장제(병뚜껑·톱니바퀴·열차·우유·지도) |
| 4 고난도 | C 30% + D 70% | 외항의 곱이 주어진 비례식, 둘레와 비, 조리법 두 단계, 부분에서 전체 |

방 하나에 기초 60문제, 나머지 40문제를 만들고, 다 푼 학생이 있으면 20문제를 더 만듭니다.
한 학생에게 같은 문제를 두 번 내지 않고, 같은 유형도 연달아 내지 않습니다. 보기 순서는 학생마다 다르게 섞습니다.

## 보안

- 정답, 채점, 상자 추첨, 시간 판정은 모두 데이터베이스 함수가 합니다. 브라우저에는 정답을 보내지 않습니다.
- 브라우저는 `rooms`, `players` 표를 읽기만 할 수 있고, 어떤 표에도 직접 쓸 수 없습니다.
- 선생님 함수는 방마다 만든 64자리 비밀 코드가, 학생 함수는 학생마다 만든 토큰이 맞을 때만 움직입니다.
- 같은 문제에 답을 두 번 보내도 점수는 한 번만 오릅니다. 게임이 끝난 뒤 온 답은 거절합니다.
- 별명과 문제 글은 HTML로 해석하지 않고 글자로만 화면에 넣습니다.

## 개인정보

- 받는 것: 별명(1~10자)과 동물 아바타뿐입니다. 실명, 번호, 연락처, 사진은 받지 않습니다.
- 숫자가 4개 이상 이어지는 별명(전화번호·학번처럼 보이는 것)은 받지 않습니다.
- 접속 IP나 기기 정보는 저장하지 않고, 방문 분석 도구도 쓰지 않습니다.
- 수업이 끝나면 **학생 기록 지우기**를 눌러 주세요. 방, 별명, 점수, 답안, 문제가 한 번에 지워집니다.
- 방 번호를 아는 사람은 그 방의 별명과 점수를 볼 수 있습니다. 학생 입장 화면에 이 내용이 안내됩니다.
- 실명 등 다른 정보가 필요해지면 학교 개인정보 담당자와 보호자 동의 절차를 먼저 확인하세요.

## 개발하며 확인한 것

- 28개 유형을 각각 1,000번씩 만들어, 모든 문제의 정답을 따로 다시 계산해 확인했습니다(오류 0건).
- 학생 7명 + 선생님 화면으로 입장부터 기록 삭제까지 실제로 눌러 보는 시험을 했습니다.
  같은 별명 거절, 새로고침 뒤 이어 하기, 골든 타임 2점, 학생 순위와 시상대 일치, 삭제 뒤 남은 기록 0건을 확인했습니다.
- 실제 Supabase 연결과 CDN 라이브러리(supabase-js 2.117.3, qrcode-generator 1.4.4, canvas-confetti 1.9.3)는 배포한 뒤 5번 점검으로 확인해 주세요.
